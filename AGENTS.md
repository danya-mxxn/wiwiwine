# Sommelier Academy: правила работы

## Назначение
Русскоязычное приложение для подготовки сомелье. React + TypeScript + Vite,
Tailwind CSS, Lucide, React Router. Только статический клиент; хостинг GitHub Pages.

## Карта
Единая карта приложения и базы знаний: [docs/PROJECT_MAP.md](docs/PROJECT_MAP.md).
Обновляйте её при изменении архитектуры, экранов, формата данных или хранения.
Реестр всех использованных сайтов и материалов с привязкой к категориям:
[docs/SOURCES.md](docs/SOURCES.md). При массовом наполнении поддерживайте его
вместе с машинным каталогом `src/data/sources.json`.

## Порядок в проекте
- Вопросы размещать только в `src/data/questions/*.json`, не в компонентах.
- Доменные функции и проверку данных держать в `src/lib`, экраны в `src/pages`.
- Общий интерфейс — `src/components`, общие типы — `src/types.ts`.
- Не добавлять отдельные отчёты, TODO-файлы, копии исходников или логи в корень.
- Документация: README для запуска и деплоя; PROJECT_MAP для архитектуры.
- SOURCES.md — единый реестр первоисточников и категорий; дополнять при добавлении
  материалов, не заводить новые несвязанные списки сайтов.
- Временные артефакты проверок не коммитить. Зависимости фиксировать lock-файлом.
- Существующие пользовательские изменения сохранять. Не удалять прогресс без подтверждения в UI.

## Инварианты
- Внутренняя навигация через HashRouter; ресурсы учитывают Vite BASE_URL.
- Категории и количество вопросов вычислять из валидной базы.
- ID вопросов стабильны и уникальны во всей базе. Индексы ответов начинаются с нуля.
- Множественный ответ правильный только при точном совпадении множества вариантов.
- Факты в поставляемых вопросах подтверждать официальными источниками; связывать
  вопросы через sourceIds с src/data/sources.json. Сохранять организацию, URL,
  название/редакцию и дату сверки; формулировать вопросы самостоятельно.
- Экзамен не раскрывает ответы до завершения; обучение показывает объяснения сразу.
- Статистика и незавершённый сеанс сохраняются в localStorage с версией схемы.
- Повреждённые JSON и недоступное хранилище не должны приводить к белому экрану.
- Никаких серверных зависимостей, секретов и платных сервисов для запуска.
- Мобильные элементы управления не меньше 44 px, фокус видим, анимации учитывают reduced motion.

## Проверка
`npm run validate`, `npm test`, `npm run build`.
При изменении сценариев проверить обучение, экзамен, повторение, восстановление
сеанса и резервную копию. При изменении деплоя проверить сборку для подпапки.
На Windows при блокировке npm.ps1 использовать npm.cmd.
