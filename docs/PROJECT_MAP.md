# Карта Sommelier Academy

## Приложение
| Маршрут после # | Экран и назначение |
| --- | --- |
| `/` | Обзор: приветствие, статистика, режимы, категории |
| `/learn` | Выбор категорий, сложности и размера обучения |
| `/categories` | Все категории, поиск, количество и прогресс |
| `/exam` | Настройка экзамена, правила и время |
| `/mistakes` | Очередь вопросов с последним неверным ответом |
| `/quiz` | Текущий сеанс, выбор ответа, обратная связь |
| `/results/:id` | Результат и разбор ответов, включая пропущенные |
| `/stats` | Статистика, история, экспорт/импорт и сброс |
| `*` | Страница с возвратом на главную |

## Код
- `src/main.tsx`: вход, HashRouter, провайдер состояния.
- `src/App.tsx`: маршруты и общая оболочка.
- `src/components/`: навигация, кнопки, карточки, индикаторы.
- `src/pages/`: экраны из таблицы выше.
- `src/types.ts`: Question, Answer, Session, Result, Progress.
- `src/lib/validation.ts`: проверка вопросов, каталога источников и ссылок между ними.
- `src/components/QuestionSources.tsx`: ссылки на источники после ответа и в разборе.
- `src/lib/questions.ts`: glob-загрузка всех JSON, индексы, категории, URL ресурсов.
- `src/lib/engine.ts`: оценивание, перемешивание, обновление статистики, завершение.
- `src/lib/storage.ts`: проверка сохранений и резервных копий.
- `src/lib/progress.tsx`: состояние, автоматическое сохранение и сообщения об ошибках.
- `src/styles.css`: тема, адаптивные сетки, состояния и анимации.
- `scripts/validate-questions.ts`: проверка всей базы в CLI/CI.
- `tests/`: тесты доменных правил и целостности данных.
- `.github/workflows/deploy.yml`: проверки, сборка и публикация на GitHub Pages.

## База знаний
Источник истины — `src/data/questions/*.json`. Каждый файл содержит массив Question.
`import.meta.glob` автоматически подключает новые файлы при следующей сборке.
Категории и подкатегории не имеют отдельного справочника: вычисляются из базы.
Сохранены исходные `grapes-regions.json`, `practice.json`, `spirits-beer.json`
со стабильными ID `wine-001`…`wine-074`. Новые материалы распределены между
`official-regions.json`, `official-winemaking.json`, `official-tasting.json`,
`official-spirits.json`, `official-beer.json`. Все вопросы остаются только в JSON.
Текущий набор: **370 вопросов, 37 категорий, по 10 в каждой**. Направления «Вино», «Крепкий алкоголь»
и «Пиво» определяются в `src/components/ui.tsx`; новую категорию для пива или
крепких напитков нужно добавить в соответствующий список функции `topic`.
Интересы пользователя: регионы, почвы, сорта, Grand Cru; тихие и игристые вина,
Champagne, Crémant, Prosecco, Franciacorta; крепкие напитки, бочки, методы и
регионы; пивоварение и стили пива. Подборка покрывает основы этих направлений.
Это авторская учебная база по официальным открытым материалам, не официальный экзаменационный банк.

| Направление | Категорий | Вопросов | Основные источники |
| --- | --- | --- | --- |
| Вино | 25 | 250 | WSET, AWRI, BIVB, CIVB, Comité Champagne, FNPEC, национальные институты и консорциумы |
| Крепкий алкоголь | 9 | 90 | WSET, SWA, BNIC, CRT, NOM-070, eCFR/TTB, Calvados France |
| Пиво | 3 | 30 | WSET Beer, BJCP 2021 |

Уровни: 90 easy, 190 medium, 90 hard. Множественный выбор — 40 вопросов.

Поля записи:
- `id`: уникальная стабильная строка, например `wine-001`.
- `category`, `subcategory`: непустые русские названия.
- `difficulty`: `easy`, `medium`, `hard`.
- `question`: формулировка; `options`: минимум два разных непустых варианта.
- `correctAnswers`: непустой массив уникальных индексов вариантов (с нуля).
- `explanation`: объяснение, обязательное для учебного разбора.
- `image`: `null`, HTTPS URL или путь относительно `public/`, без начального `/`.
- `sourceIds`: массив ID официальных материалов из `src/data/sources.json`.
  Поле необязательно для совместимости со сторонними наборами; все поставляемые
  вопросы имеют хотя бы один источник, что проверяется тестами.

Каталог `src/data/sources.json` содержит `id`, `organization`, `title`, `url`,
`checkedAt` (дата проверки YYYY-MM-DD). Адреса HTTPS, без учётных данных.
Сейчас в каталоге 105 материалов с 30 доменов. Полный читаемый список сайтов,
материалов и их категорий: [SOURCES.md](SOURCES.md). При дальнейшем массовом
наполнении обновлять оба представления по фактическим `sourceIds`.
`validateSources` проверяет каталог; `validateSourceLinks` обнаруживает отсутствующие ID.
Каждая ссылка указывает на материал с фактической основой конкретного ответа.
Дата сверки текущего набора — 2026-11-09. Для BJCP зафиксирована редакция 2021,
для спецификаций WSET редакция указана в заголовке источника. Перед изменением
числовых норм сверяйте актуальную спецификацию соответствующего наименования;
избегайте переноса правил одного региона на другой. При расхождении переводов
проверяйте оригинал (например, испанскую страницу CRT о выдержке Reposado).

После ответа в обучении/повторении отображаются организация, название материала,
ссылка и дата проверки. В экзамене источники доступны только в итоговом разборе.
Внешние ссылки открываются отдельно с `noopener noreferrer`. Для прохождения
занятий не требуется сетевой доступ к источникам: вопросы включены в сборку.
Формулировки написаны самостоятельно; закрытые экзамены не импортируются.

Один индекс означает одиночный выбор, несколько — множественный.
Вопрос с иллюстрацией включён в практическую часть. Локальные изображения — `public/illustrations/`.
Для добавления тысячи вопросов: добавить JSON-массивы, выполнить validate/test/build.
Нельзя менять ID при редактировании формулировки: на него ссылается прогресс.
Некорректный файл или запись изолируется; CLI завершает проверку с ошибкой,
UI показывает предупреждение и использует оставшуюся валидную базу.

## Прогресс и сеансы
Ключ `sommelier-academy:v1` в localStorage; схема `version: 1`.
- `records`: по ID — число попыток, правильных ответов, последний результат и дата.
- `history`: последние 100 завершённых сеансов с ответами.
- `active`: текущий сеанс с порядком вопросов, выбором, индексом и сроком экзамена.

Точность = правильные попытки / все попытки. Прогресс категории = вопросы,
на которые хотя бы раз отвечали / доступные вопросы. Повторение = последний ответ неверный.
Каждый подтверждённый ответ сразу учитывается в records, в том числе в незавершённом сеансе.
После правильного повторения вопрос выходит из очереди ошибок. Перезагрузка
восстанавливает сеанс, абсолютный срок экзамена продолжает действовать.
Смена устройства поддерживается экспортом/импортом JSON через статистику.
Импорт заменяет локальное состояние после явного подтверждения. Автосинхронизации нет.

## Хостинг
Vite base по умолчанию `./`; workflow задаёт base по имени репозитория.
HashRouter не требует серверного rewrite или 404-хака. Данные включены в сборку,
изображения поставляются из public. Инструкция пользователя — в README.md.
